# Documents to share

PDF copies of the guides for testers. The Markdown files are the source; after editing one, run
`bash scripts/share/make_share_pdfs.sh` to refresh these PDFs.

| PDF | Source | Use it to |
|---|---|---|
| `TEST_ON_COMPUTER.pdf` | `docs/TEST_ON_COMPUTER.md` | Try the app on a Mac (or Windows laptop) with a virtual Pixel 8, including scanning |
| `INSTALL_ON_ANDROID.pdf` | `docs/INSTALL_ON_ANDROID.md` | Install the app on an Android phone |
| `PIXEL_SCAN_TEST_GUIDE.pdf` | `docs/task4c/PIXEL_SCAN_TEST_GUIDE.md` | Scan test labels and check the result screen |
| `FUNCTIONAL_TEST_PLAN.pdf` | `docs/FUNCTIONAL_TEST_PLAN.md` | Typed-entry tests for every result type |
| `EXTENDED_DRUG_LIST.pdf` | `data/proposals/EXTENDED_DRUG_LIST.md` | Review the proposed extended drug list (196 rows) and how it was made |
| `DATA_SCHEMAS.pdf` | `docs/DATA_SCHEMAS.md` | The schemas of the drug catalog, exclusion policy and on-phone database |
| `scan-test-labels-SYNTHETIC.pdf` | `scripts/scanner_lab/make_test_sheet.py` | Seven made-up labels to scan (real public drug codes; all personal details invented) |

The app files (APKs) are not stored in the repository; they are shared separately.
